# 데블스 플랜 게임 모음

「데블스 플랜」 게임, 교실에서 따라하기 — 수업에서 쓰는 **진행자 도구 모음**입니다.
전부 빌드 도구 없는 정적 페이지라 주소만 열면 폰·태블릿·교실 PC 어디서든 돌아갑니다.

- 배포: <https://chan7881.github.io/devils-plan/>
- 로그인·설치·계정이 필요 없습니다. **진행자 단말 한 대**에서 전부 진행합니다.
- 외부 서비스에 의존하지 않습니다 — 학교 망에서 구글 클라우드가 막혀도 그대로 열립니다.

### 규칙 레이스의 세 가지 판

지금은 원본 세 가지를 그대로 두었습니다. 하나로 합치는 작업이 예정되어 있습니다.

| 주소 | 판정 방식 | 초능력 |
|---|---|---|
| `/race/` | 5·6등이 최종 1등, 4·7등이 2등 (대칭 판정) | 10종 |
| `/race/variant-middle2.html` | 1등과 꼴찌 탈락, 2~9등 생존 | 7종 |
| `/race/variant-manual.html` | 대칭 판정, 초능력을 진행자가 수동 처리 | 별도 구성 |

## 구조

빌드 도구 없음. 순수 HTML/CSS/ES 모듈, CDN 의존 없음.

```
index.html            허브 — 게임 목록 · 피스 배분표
styles.css            허브 공용 스타일
common/js/pieces.js   피스 배분 순수 로직 (여러 게임이 공유)
common/js/tests.js    그 검증
common/test.html      브라우저에서 여는 자체 검증 페이지
<게임>/index.html      게임마다 한 폴더
docs/                 규칙 원문 · 원본 앱 대조 기록
```

`common/js/pieces.js`에 **피스 배분 규칙을 한 곳으로 모았습니다.** 시크릿 넘버·기억의 조각·
수식 하이로우가 같은 규칙(공동 등수 시 차순위 피스까지 모아 균등 분배, 나머지 버림, 동점 수만큼
차순위 제거)을 쓰는데 미묘해서 게임마다 따로 구현하면 반드시 어긋납니다.

## 테스트

브라우저에서 <https://chan7881.github.io/devils-plan/common/test.html> 을 열거나,
node로 한 번에 돌립니다.

```bash
node --input-type=module -e "
const m = await import('file:///<절대경로>/devils-plan/common/js/tests.js')
const r = m.runAll()
console.log('PASS ' + r.filter(x=>x.ok).length + ' / FAIL ' + r.filter(x=>!x.ok).length)
for (const x of r) if (!x.ok) console.log(x.label)"
```

결과 객체의 필드는 **`label`**입니다(`message`가 아닙니다).
